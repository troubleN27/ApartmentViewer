# Новый дом — выбор квартиры в новостройке (2D + 3D)

Сайт застройщика жилого комплекса. Покупатель выбирает квартиру на шахматке дома, смотрит планировку сверху с размерами и площадями, заходит внутрь в 3D и гуляет по квартире на высоте своих глаз, а затем оставляет заявку на просмотр.

Стек: Node.js + Express, чистые HTML/CSS/JS (ES-модули, без сборщиков), Canvas 2D, Three.js. Данные лежат в JSON-файлах, состояние пользователя — в `localStorage`.

## Запуск

```bash
npm install
npm run seed     # сгенерировать дом: 9 этажей × 6 квартир → data/apartments.json
npm start        # http://localhost:3000
```

Тесты (геометрия, генератор, API):

```bash
npm test
```

`npm run seed -- 123` генерирует другой вариант дома. Порт меняется переменной `PORT`.

## Как пользоваться

1. **Шахматка** — сетка «этаж × квартира». Цвет ячейки — статус (свободна, бронь, продана). Чипы сверху фильтруют по комнатности и цене, звёздочка добавляет квартиру в избранное.
2. **Планировка** — нажмите на ячейку. На плане видны комнаты с площадями, стены, двери с дугой открывания, окна и размерные линии в сантиметрах. При наведении на комнату показываются её размеры.
3. **3D** — кнопка «Смотреть в 3D». Сцена строится из тех же данных, что и план.
4. **Заявка** — кнопка «Записаться на просмотр»: имя и телефон в формате `+998XXXXXXXXX`. Заявки сохраняются в `data/leads.json`. Для проданных квартир запись недоступна.

Язык интерфейса (RU / UZ) переключается в шапке. Язык, рост, фильтры, избранное, отделка, выбранная квартира и черновик заявки запоминаются.

## Управление в 3D

| Режим | Управление |
| --- | --- |
| Облёт | зажать левую кнопку мыши — вращение, правую — сдвиг, колесо — масштаб |
| Прогулка | `W` `A` `S` `D` или стрелки — идти, мышь — осмотреться, `Shift` — быстрее |
| Выход | `Esc` или кнопка с крестиком |

- Перед прогулкой нужно указать рост (120–220 см): камера ставится на высоту глаз, «рост − 12 см».
- Прогулка начинается у входной двери. Сквозь стены пройти нельзя, в дверные проёмы — можно.
- В углу экрана — мини-карта с вашим положением и направлением взгляда.
- Переключатель «Whitebox / Чистовая» меняет отделку, кнопка справа — полноэкранный режим.
- `Esc` в прогулке возвращает в облёт, `Esc` в облёте закрывает 3D.

## Dev-режим

Откройте `http://localhost:3000/?dev=1` — в углу появится панель:

- **Случайная квартира** — генерирует валидную квартиру по seed из поля (пустое поле — случайный seed). Один и тот же seed всегда даёт одну и ту же квартиру.
- **Сбросить localStorage** — удаляет все ключи с префиксом `nd:` и перезагружает страницу.

Сгенерированные квартиры хранятся только в браузере, заявку на них оставить нельзя.

## Структура

```
server.js              Express: статика, /vendor (three, шрифты), API
scripts/seed.js        генерация data/apartments.json
data/                  apartments.json, leads.json
public/js/model.js     геометрия, валидация, коллизии (чистые функции)
public/js/generator.js случайная квартира по seed
public/js/chess.js     шахматка
public/js/plan2d.js    планировка на Canvas, мини-карта
public/js/scene3d.js   3D-сцена и облёт
public/js/walk.js      прогулка от первого лица
public/js/app.js       экраны и общее состояние
public/js/i18n.js      словари RU/UZ
tests/                 тесты на node:test
```

API: `GET /api/apartments`, `GET /api/apartments/:id`, `POST /api/leads`. Подробные правила проекта — в `CLAUDE.md`.

## Известные ограничения

- Прогулке нужны клавиатура и мышь (Pointer Lock), на телефоне доступен только облёт.
- `Esc` в полноэкранной прогулке браузер обрабатывает сам: он одновременно отпускает мышь и выходит из полноэкранного режима. Сцена при этом остаётся открытой в режиме облёта.
- После выхода по `Esc` браузер около секунды не даёт снова захватить мышь — если взгляд не двигается, щёлкните по сцене.
- Планировки генерируются делением прямоугольника, поэтому комнаты близки по площади и квартиры всегда прямоугольные.
